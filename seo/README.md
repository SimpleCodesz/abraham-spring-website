# AbrahamSpring.co.uk organic-search operating system

`ownership.json` is the canonical map between a search territory, its commercial landing page, supporting pages, tracked keywords and claims boundary.

## Publishing contract

1. Give every commercial query family one canonical landing page.
2. Give every authority article one primary informational query and one commercial destination.
3. Check claims against authoritative sources before publication; preserve the non-clinical boundaries in `guardrails`.
4. Add every indexable page to `sitemap.xml`, use a self-referencing canonical and expose it through a real internal link.
5. Run `node scripts/validate-seo.mjs` before review.
6. Add the approved query and exact target URL to SE Ranking, then capture the publication date and first indexation/ranking evidence.
7. Review GSC and Bing query/page data weekly. Expand pages from observed impressions and intent; do not produce articles solely because a keyword tool suggests them.

## Current measurement

The article backlog in `ownership.json` is prioritised but not automatically approved for publication. Each article needs an evidence pack, Abraham-voice edit, internal-link review and independent QA.
